# Product Management System Application

A simple full-stack Product Management System CRUD app built with React, Vite, Express, and MongoDB.

## Features Implemented
- User registration and login
- JWT-based authentication
- Protected routes for authenticated users
- Product CRUD operations (create, read, update, delete)
- Admin-only user management access
- Clean dashboard interface for managing products

## Tech Stack
- Frontend: React, Vite, Axios
- Backend: Node.js, Express, MongoDB, JWT, Passport

## Run Locally
1. Install backend dependencies:
   - cd backend
   - npm install
2. Install frontend dependencies:
   - cd frontend
   - npm install
3. Start the backend:
   - cd backend
   - npm start
4. Start the frontend:
   - cd frontend
   - npm run dev

> Note: A .env file is included intentionally for evaluation purposes.
